# Pine City Zoo

**Live site:** https://jesskg.github.io/Pine-City-Zoo-JG/

---

## What this is

A multi-page zoo app built during my time at the **FNB App Academy** in 2025.

It's designed like a mobile app - fixed header with a logo, top navigation (Animals, Map, Places), and bottom navigation (Weather, Feedback). You can browse 9 animals with descriptions, explore zoo locations like the Amphitheatre and Monkey Trail, check the weather forecast, and leave feedback.

---

## Pages

- **Map** — Home screen with the zoo map
- **Animals** — List of 9 animals (Elephants, Gemsbok, Giraffe, Gorilla, Koala, Lions, Monkeys, Pandas, Wartogs)
- **Places** — Zoo attractions (Amphitheatre, Insect House, Monkey Trail, The Lost Forest)
- **Weather** — Pine City weather forecast
- **Feedback** — Contact form

## The honest context

This was an early project from my time at the FNB App Academy - one of the first times I built something that felt like a real app rather than just a webpage.

Looking at the code now, I can see things like missing meta tags, hardcoded static weather data, and a feedback form that doesn't actually submit anywhere. That's not me cutting corners - that's exactly where my skills were at the time.

What I was learning here:

- Multi-page site architecture with consistent navigation
- Fixed positioning for headers and bottom tabs (mimicking a native mobile app)
- CSS layout with floats and fixed elements
- Linking multiple pages together with a clear user flow
- Organising content across a larger project structure

This project showed me that structure and navigation matter just as much as individual pages. It was my first time thinking about a site as a system rather than a collection of files.
